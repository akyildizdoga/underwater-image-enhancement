# Underwater Image Enhancement Using Classical Image Processing Techniques

## Project Overview

This project aims to improve the visual quality of underwater images using classical image processing techniques.

Underwater images often suffer from blue or green color casts, low contrast, and reduced visibility due to light absorption and scattering in water.

The project compares four image enhancement approaches without using artificial intelligence or deep learning.

**Course:** CENG376(1) - Image Processing  
**Project Type:** Image Enhancement and Evaluation

## Objectives

- Reduce underwater color distortion.
- Improve image contrast and brightness.
- Compare different classical enhancement techniques.
- Evaluate the enhanced images using PSNR and SSIM.
- Analyze the strengths and limitations of each method.

## Dataset

The project uses the Underwater Image Enhancement Benchmark (UIEB) dataset.

The dataset provides original underwater images and corresponding enhanced reference images.

Dataset source: https://li-chongyi.github.io/proj_benchmark.html

The reference images are published benchmark targets, not outputs generated by this project.

## Implemented Methods

### 1. Gray-World White Balance

Estimates the average intensity of each color channel and rescales the channels to reduce color imbalance.

### 2. CLAHE

Applies Contrast Limited Adaptive Histogram Equalization to the lightness channel in LAB color space to improve local contrast.

### 3. Gamma Correction

Uses a power-law intensity transformation to adjust image brightness.

The initial experiment uses gamma = 0.6.

### 4. Combined Enhancement

Applies Gray-World White Balance followed by CLAHE to improve both color balance and local contrast.

## Initial Experimental Results

The first experiment was conducted using the UIEB image `8_img_.png`.

The enhanced outputs were compared with the corresponding UIEB reference image.

| Method | PSNR (dB) | SSIM |
|--------|-----------|------|
| Original | 11.87 | 0.7398 |
| Gray-World | 12.92 | 0.8031 |
| CLAHE | 12.79 | 0.8072 |
| Gamma Correction | **15.28** | 0.8271 |
| Combined Enhancement | 13.93 | **0.8445** |

### Initial Observations

- Gamma Correction achieved the highest PSNR in this experiment.
- Combined Enhancement achieved the highest SSIM.
- CLAHE improved local contrast but did not fully correct the green color cast.
- Gray-World White Balance reduced the original color imbalance but introduced noticeable reddish tones in this image.
- The results demonstrate that different enhancement methods can perform differently depending on the evaluation criterion.

These results are preliminary and are based on a single image. Further experiments are required before drawing general conclusions.

## Evaluation Metrics

**PSNR (Peak Signal-to-Noise Ratio):** Measures pixel-level similarity between an enhanced image and its reference.

**SSIM (Structural Similarity Index):** Measures structural similarity between an enhanced image and its reference.

Since UIEB reference images are enhanced benchmark targets rather than physical ground truth, numerical scores alone do not establish perceptual image quality.

## How to Run

Install the required Python packages:

```bash
pip install opencv-python numpy matplotlib scikit-image
```

Download the UIEB dataset and organize the files as follows:

```text
data/
    raw-890/
    reference-890/
```

Run the individual enhancement methods:

```bash
python gray_world.py
python clahe.py
python gamma.py
python combined.py
```

Run the evaluation:

```bash
python evaluate.py
```

The scripts currently use the example image `8_img_.png`. Both the original and matching reference must be present in their respective dataset folders.
